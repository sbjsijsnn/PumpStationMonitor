# 异常处理与边界审计

## 已检查

- 所有生产代码 catch 均记录日志/控制台诊断或重新抛出，无空 catch、无 Thread.Sleep 无限循环。
- Core 无 WPF 引用；所有 ObservableCollection 与图表集合在 DispatcherTimer/UI 命令上下文更新。
- TCP 使用 ReadExactlyAsync，验证协议号、事务号、站号、长度与 PDU；RTU CRC 小端，超时关闭端口。
- 读请求重试有上限、退避与取消；写请求应答丢失不自动重发。
- 默认相邻点位合并为 6 次请求；不同设备/功能不混组，Float32 两寄存器不越协议边界。
- 数据库参数化查询，外键、索引、WAL；UTC 毫秒时间，显示转本地。
- 历史 Channel 有界，满队列背压，失败批次保留重试；正常关闭先停生产再排空。
- 活动报警重启恢复 ID；规则/点位修改与采集串行；活动关联项不能删除或修改。
- 用户操作在服务层重新查询角色；最后一个管理员不可禁用/降级，当前账号不可删除。
- CSV 加引号、转义双引号，公式前缀加单引号；密码不进入日志。
- UI 坏质量与过期数据显示破折号；报警自动刷新保留当前选择；趋势与历史显示数量有界。
- Release 构建启用 TreatWarningsAsErrors；NuGet 依赖锁定，仅公共源；直接与传递依赖漏洞扫描未报告漏洞（检查时点见验收记录）。

## 已知限制

- RTU 真实/虚拟串口未实测，SerialPort.Open 的底层驱动阻塞无法完全由 CancellationToken 中断。
- SQLite 异步方法不提供真正异步磁盘 I/O；后台写入和有界批次降低影响，但大型查询仍应限制范围。
- 非正常断电/强杀时内存中尚未提交的历史批次可能丢失；正常退出已经验证排空。
- 同一数据库按单 App 实例使用；未提供跨实例协调或生产级冗余。
- 操作员能确认报警，不能配置和控制；数据库文件本身不做加密，需依赖本机文件权限。
- 查询和报警 CSV 单次上限 10,000 条，未提供跨页全量导出；曲线为显示抽样而非原始完整数据。
- 模拟器仅监听 loopback，不代表 PLC 现场互操作验收；累计运行由模拟初值加运行时间。
- .NET 10 的 VS 2022 构建兼容性未验收，CLI 和自包含发布版已验证。
