# 演示脚本

## M1 可运行演示（约 3 分钟）

1. 在终端 A 启动模拟器，说明 loopback:1502、站号 1 与点表零基地址。
2. 在终端 B 运行 ConsoleDemo，展示单寄存器、多个寄存器、线圈回读通过和变化液位。
3. 在 A 输入 `fault 1` 与 `level 9.5`，重新运行 B，观察故障输入 True、液位 9.50 m。
4. 在 A 输入 `offline`，运行 B，观察超时及非零退出。示例首先写入，因此不会对该控制请求自动重试；读请求的指数退避和恢复由 IntegrationTests 验证。
5. 在 A 输入 `recover`，再次运行 B，观察成功连接；运行 `dotnet test -c Release` 展示全部测试。
6. A 输入 `quit` 结束。
