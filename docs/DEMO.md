# 五分钟演示

| 时间 | 操作 | 讲解 |
|---|---|---|
| 0:00 | 双击 Start-Demo.cmd，admin / Admin123! 登录 | 自带模拟器，无需硬件；四设备、23 点 |
| 0:30 | 总览启动 1# 泵，观察频率 50 Hz、电流变化 | 控制应答后下一轮更新工况，控制有权限和日志 |
| 1:00 | 趋势选择集水池液位，窗口 1 分钟 | 1 秒采集，后台采集与 UI 分离 |
| 1:30 | 命令窗口输入 fault 1 | 运行状态关闭，故障报警产生 |
| 1:50 | 报警中心选中报警、确认 | 确认只是已知悉，故障仍然活动 |
| 2:15 | 输入 level 9.5，观察 H 与 HH | 独立规则带延时、死区，紧急和警告等级 |
| 2:40 | 输入 offline | 等待超时与重连，实时质量变无效/过期，不显示假正常 |
| 3:10 | 输入 recover | 下一轮自动恢复；报警恢复时间保留 |
| 3:35 | 历史查询选择 level，时间覆盖当前，查询与回放 | 显示采样记录，播放/暂停、拖动进度 |
| 4:15 | 报警历史查询，导出 CSV | 确认人、发生/恢复/确认时间可追踪 |
| 4:40 | 系统设置展示点表和规则，说明操作员无修改和控制权限 | 业务层二次授权，密码不存明文 |

收尾关闭 App，再在命令窗口输入 quit。运行环境首次无历史时先采集几十秒。日期输入使用本机时间，结束时间需覆盖本次演示。

技术追问：打开 Core/Protocol/ModbusFrames.cs 解释 CRC 与 MBAP，打开 Data/Services/HistoryWriter.cs 解释 Channel 与批次，打开 docs/METRICS.md 展示真实测量口径。
