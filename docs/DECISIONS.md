# 技术决策

| 决策 | 为什么 | 备选 | 代价 |
|---|---|---|---|
| .NET 10 | 本机仅有 10.0.400 SDK，按任务要求适配 | 安装 .NET 8 | 需另外核实 IDE 支持，当前 CLI 验收 |
| Core 纯 .NET | 协议和报警可独立测试，后续 UI 不影响通信 | 直接放在 WPF 中 | 要设计清楚接口 |
| 自研 PDU + 两种封装 | 可直接解释 MBAP、CRC、应答校验 | 通用 Modbus 客户端库 | 协议边界和硬件兼容性由本项目负责 |
| ILogger 抽象 | 日志输出方式不绑定协议 | 在协议内直接写文件 | 宿主需提供实现，M1 控制台，M2 Serilog |
| 单请求异步锁 | 串口不可交叉收发，TCP 更易关联事务 | TCP 多请求流水线 | 高并发吞吐受限，四设备场景足够 |
| 读重试、写不重发 | 丢失应答无法判断设备是否已执行 | 全部自动重试 | 操作者需要回读确认写入结果 |
| 本地 TCP 从站 | 无硬件也能演示，并覆盖真实网络字节流 | 外部模拟工具 | 只监听 loopback，非生产 PLC 仿真 |
| 报警时间由采样携带 | 延时测试可确定，方便后续回放 | 直接读取系统时钟 | 输入需按时间顺序串行调用 |
| xUnit + loopback 测试 | 同时验证字节级逻辑与传输行为 | 全部 mock | 集成测试涉及系统网络调度 |

M2～M5 将按任务选用 SQLite+Dapper、Channel、Hosting、Serilog、CommunityToolkit.Mvvm、HandyControl 和 LiveCharts2；尚未安装或验收这些后续依赖，届时补充版本、授权检查与取舍记录。
